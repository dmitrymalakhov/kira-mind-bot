# AGENTS.md

Основные инструкции репозитория для coding agents.

Этот файл намеренно сделан коротким. Сначала прочитай его, затем загрузи указанные ниже файлы.

## Обязательный порядок чтения
1. `CODEX-RULES.MD` — обязательные правила репозитория и операционные ограничения.
2. `CODEX.MD` — проектные решения, архитектурные заметки и локальная история.

## Приоритет инструкций
1. `CODEX-RULES.MD`
2. `CODEX.MD`
3. Остальные документы репозитория (`README.md`, `ROADMAP.md`, `CHANGELOG.md`)

Если инструкции конфликтуют, следуй файлу с более высоким приоритетом.

## Совместимость между агентами
- Считай `AGENTS.md` кросс-инструментальной точкой входа для этого репозитория.
- Долгоживущие правила храни в `CODEX-RULES.MD`.
- Решения и исторический контекст храни в `CODEX.MD`.
- Не дублируй длинные блоки правил в нескольких файлах, если инструмент умеет переходить по ссылкам и ссылочным указаниям.

## Критичные правила
- Никогда не коммить напрямую в `main`; сначала создай рабочую ветку.
- Перед планированием, изменением кода или запуском команд проекта прочитай `CODEX-RULES.MD` и `CODEX.MD`.
- Не повторяй подходы, которые уже были зафиксированы в `CODEX.MD` как неудачные.
- Решай задачу для класса сценариев: устраняй общую причину, учитывай контекст и смежные случаи в текущей тематике, повышай качество и скорость полного сценария. Не подгоняй поведение под отдельную фразу или пример.
- Всегда покрывай всю новую функциональность автоматическими тестами. После изменения кода или сценария сохраняй работоспособность прежних сценариев, добавляй необходимые регрессии и запускай полный набор `npm test`. Подробные обязательные требования — в разделах «Системные решения» и «Проверки и регрессии» файла [CODEX-RULES.MD](CODEX-RULES.MD).
- Убирай за собой временные артефакты разработки и тестирования: картинки, скриншоты, бэкапы, пробные файлы и другие ненужные результаты работы, включая игнорируемые Git. Перед завершением задачи и коммитом удаляй свой мусор, сохраняя нужные файлы проекта и чужие изменения; подробности — в разделе «Repository Hygiene» файла [CODEX-RULES.MD](CODEX-RULES.MD#repository-hygiene).
- Commit message должны использовать Conventional Commits и быть написаны по-русски.
- Существенные изменения должны быть отражены в `CHANGELOG.md` в формате, который уже используется в самом файле.

- Команды, код, пути и идентификаторы оставляй в исходном виде.
