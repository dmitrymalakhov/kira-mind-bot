# Настройки моделей

В админке откройте настройки моделей. Выберите три предпочтения и нажмите «Применить»:

- **Цензура диалога:** обычные модели либо подходящая модель свободного диалога. Само значение не снимает ограничения произвольного провайдера.
- **Стоимость:** низкая, средняя или высокая. Задаёт класс моделей и предел одного ответа. Повторы, число запросов, поиск и входные токены также влияют на счёт; это не денежная квота.
- **Качество:** обычное или высокое. Для сложных задач меняет глубину рассуждения в пределах выбранного класса стоимости. Высокое качество при низкой стоимости не включает Sol или Astra.

Перед сохранением видны доступность сочетания, место обработки и модели по задачам. Если своих подключений нет, используются доступные API сервиса. Для свободного диалога нужны подходящая модель LM Studio или явно настроенная сервисная модель. Если их нет, интерфейс объясняет причину и не применяет выбор. При отказе закреплённой модели обычный облачный текстовый fallback не включается. Поиск, зрение, голос и embeddings сохраняют специализированные подключения. Свободный режим не отключает подтверждения действий и изоляцию памяти.

Список установленных локальных моделей приходит из LM Studio. В настройках локальных ролей можно явно отметить «Использовать эту модель для свободного диалога»; при замене модели отметка снимается. Метки `uncensored/obliterated/heretic` помогают выбрать кандидата, но не гарантируют поведение весов. Оператор также может указать установленный ID через `LM_STUDIO_FREE_MODEL`. Для общего gateway можно задать `KIRA_FREE_DIALOGUE_MODEL` — ID обслуживаемой им модели свободного диалога; transport и ключ остаются общими OpenAI-compatible настройками. Эти ID не принимаются от клиента в предпочтениях.

Старый сохранённый профиль продолжает работать до явного применения предпочтений. В дополнительных настройках можно вернуться к ручному выбору. Параметры локальных ролей меняются отдельно и продолжают действовать без переписывания памяти. Платные фоновые функции и максимальная экономия настраиваются отдельно: выбор стоимости сам по себе их не включает.

## API

`GET /api/v1/model-preferences` возвращает режим `automatic/manual`, предпочтения, действующий план, доступность 12 сочетаний и состояние подключений без ключей. Настройка действует в рамках аккаунта. Явный прежний режим приложения имеет приоритет только в его диалоге.

`PUT /api/v1/model-preferences`, с обычным Bearer текущего аккаунта:

```json
{"censorship":"on","cost":"low","quality":"high"}
```

Другие поля, в том числе credentials, account/user IDs и произвольные model IDs, запрещены. Сервер проверяет ресурсы до записи; базовый профиль и полный план сохраняются одной атомарной операцией в `bot_settings`. Изменения подхватываются в течение пяти секунд. Фоновые продолжения используют снимок политики исходного сообщения. API не меняет профиль embeddings и не переиндексирует память.

## Короткий диалог

Точное «Ты тут?» получает короткое подтверждение без классификатора, retrieval или фонового задания. Приветствия и благодарности не становятся исследованием из-за ошибочного сигнала модели. Составные просьбы, пересылки, ответы на другие сообщения и активные подтверждения сохраняют обычную обработку. Отмена действительно долгой работы по-прежнему доступна через `/cancel_deep`; новая реплика останавливает старый разбор.
