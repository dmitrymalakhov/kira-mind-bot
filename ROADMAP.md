# ROADMAP

## OpenAI Model Config Rollout

- Разделить "рефакторинг конфигурации моделей" и "удешевление по умолчанию" на разные этапы.
- Для безопасного rollout оставить исходные production-дефолты в `config.ts`, чтобы вынос моделей в конфиг не менял поведение без явного `env`.
- Перевод на более дешёвые модели (`gpt-5.4-mini`, `text-embedding-3-small` и т.д.) включать отдельным коммитом или только через заданные `OPENAI_MODEL_*` переменные.
- Перед сменой дефолтов проверить качество в трёх критичных зонах:
  - классификация интентов и dedup;
  - качество retrieval после смены embedding-модели;
  - сценарии анализа переписки и memory extraction.
