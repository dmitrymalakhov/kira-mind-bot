# Kira Mind Bot

Персональный Telegram-ассистент с долговременной памятью, напоминаниями, дневником здоровья, доступом к интернету, браузерными действиями, анализом переписок и веб-панелью управления.

Бот разворачивается на своём VPS через Docker Compose. Данные памяти и напоминаний хранятся в PostgreSQL и Qdrant на вашем сервере; внешние API используются только для конкретных возможностей: OpenAI, Telegram User Client, Google Maps и Ideogram.

---

## Быстрый старт

Нужно: VPS с Ubuntu/Debian, Docker-доступ на самой машине и уже поднятый Xray SOCKS5 на `172.17.0.1:10808`.

```bash
git clone <repo>
cd kira-mind-bot
./server-install.sh
```

Серверный установщик:

1. проверит Docker и при необходимости установит его прямо на VPS;
2. проверит доступность Xray SOCKS5 на `172.17.0.1:10808`;
3. спросит ключи и базовые настройки;
4. запишет `.env.production` с обязательными `HTTP_PROXY` / `HTTPS_PROXY` / `ALL_PROXY` / `NO_PROXY`;
5. сгенерирует `.env`, `personality.json` и состояние админ-панели;
6. соберёт и поднимет PostgreSQL, Qdrant, Kira и админ-панель прямо на VPS;
7. выведет URL, логин и пароль панели управления.

Обновление после изменений в репозитории:

```bash
git pull && ./server-install.sh --skip-config
```

Если нужен второй бот `SergeyBrainBot`, используй:

```bash
git pull && ./server-install.sh --skip-config --with-sergey
```

Локальный сценарий `install.sh` / `deploy.sh` остаётся как отдельный legacy-flow для деплоя с локальной машины на удалённый VPS. Для этого пути сохраняется старый `docker-compose.yml`, а `server-install.sh` использует отдельный `docker-compose.server.yml`.

## Обязательный VPN-контур

Перед запуском `server-install.sh` на VPS уже должен работать Xray SOCKS5 на `172.17.0.1:10808`.

Скрипт записывает в `.env.production`:

```text
HTTP_PROXY=socks5h://172.17.0.1:10808
HTTPS_PROXY=socks5h://172.17.0.1:10808
ALL_PROXY=socks5h://172.17.0.1:10808
NO_PROXY=localhost,127.0.0.1,postgres,qdrant
```

Это обязательно для серверного сценария. Смысл схемы:

- весь внешний HTTP(S)-трафик контейнеров идёт через VPN;
- локальные сервисы Docker Compose не уходят через VPN благодаря `NO_PROXY`;
- не используется `network_mode: container:xray`;
- не нужно менять `DATABASE_URL` и `QDRANT_URL`.

Если Xray на `172.17.0.1:10808` недоступен, `server-install.sh` завершится с ошибкой до сборки контейнеров.

## Что умеет бот

### Диалог и память

- Ведёт свободный диалог с учётом истории и долговременной памяти.
- Запоминает факты по просьбе и автоматически извлекает важные факты из разговоров.
- Умеет забывать найденный факт с подтверждением.
- Ищет память по доменам: `work`, `health`, `family`, `finance`, `education`, `hobbies`, `travel`, `social`, `home`, `personal`, `entertainment`, `contacts`, `general`.
- Хранит версии фактов, уверенность, теги, связи между фактами и эпизодами.
- Строит сводку того, что знает о владельце.
- Показывает инсайты, качество памяти и историю изменений факта.
- Консолидирует старые факты в эпизоды и главы памяти.
- Запускает режим рефлексии: накапливает личные сообщения, отсеивает шум и сохраняет содержательные факты.
- Запускает самоизучение: анализирует собственные функции, ограничения, фоновые ошибки и сохраняет отчёт в самопамять.

Примеры:

```text
Запомни, что я работаю над Kira Mind Bot
Что ты помнишь обо мне?
Забудь, что я живу в старом районе
Покажи историю факта про работу
Изучи себя и свои потребности
```

### Напоминания и планирование

- Создаёт одно или несколько напоминаний естественным языком.
- Поддерживает перенос, редактирование, отмену, завершение и просмотр активных напоминаний.
- Понимает повторяющиеся напоминания.
- Может отменять или переносить все напоминания за период.
- Поддерживает напоминания в личном чате, группах и контексте контактов.
- Присылает утренний дайджест с напоминаниями на день.
- Может ставить напоминания из договорённостей, найденных в переписке.

Примеры:

```text
Напомни завтра в 9:30 позвонить врачу
Каждый понедельник в 10 напоминай проверить отчёты
Перенеси напоминание про врача на пятницу
Измени напоминание про отчёт: текст: проверить финальные цифры
Отмени все напоминания на сегодня
```

### Telegram User Client

Если настроить `TELEGRAM_API_ID`, `TELEGRAM_API_HASH` и `TELEGRAM_SESSION_STRING`, бот получает доступ к вашему Telegram-аккаунту через пользовательскую сессию.

Возможности:

- показывает непрочитанные сообщения за последние 24 часа;
- суммаризирует входящие;
- раз в день вечером присылает Inbox Guardian — только незакрытые вопросы и диалоги, где от вас явно ждут ответа;
- отмечает сообщения как прочитанные;
- анализирует личную переписку с контактом;
- анализирует групповые чаты и группы чатов;
- сохраняет найденные факты в долговременную память;
- синхронизирует и показывает контакты;
- разрешает роли вроде “жена”, “мама”, “коллега” через память;
- строит психологический портрет контакта по переписке;
- готовит черновики сообщений от вашего имени;
- отправляет сообщения контактам и группам после подтверждения;
- планирует отложенную отправку;
- ведёт переговоры от вашего имени: начинает диалог, следит за ответами и при необходимости спрашивает, что ответить;
- фоново изучает личные переписки и индексирует новые факты, если включён соответствующий режим.

Примеры:

```text
Покажи непрочитанные сообщения
Изучи чат с женой за неделю и запомни важное обо мне
Напиши маме, что я задержусь на полчаса
Отправь в чат команды: завтра встречаемся в 11
Договорись с поставщиком о доставке цветов завтра
```

### Дневник здоровья

Бот ведёт дневник наблюдений. Это не диагноз и не медицинская рекомендация.

Можно фиксировать:

- еду и напитки;
- симптомы и уровень дискомфорта;
- кожу, зуд, покраснения, высыпания;
- давление, пульс и фото тонометра;
- лекарства;
- активность, контакт с возможными триггерами и заметки;
- фото еды, кожи и показаний приборов;
- подсказки, какие детали стоит дописать для более точного анализа;
- тревожные признаки в записи без постановки диагноза;
- наблюдательные паттерны: что чаще встречалось перед симптомами;
- follow-up напоминания, чтобы проверить динамику через 1-24 часа;
- экспорт дневника за период документом.

Примеры:

```text
Запусти дневник здоровья
Запиши: съел креветки, через час зуд на руках 6 из 10
Запиши давление 120/80, пульс 72
Сохрани фото того, что я ем
Выгрузи дневник здоровья за 30 дней
```

### Интернет, браузер и карты

- Ищет актуальную информацию через OpenAI web search.
- Выполняет задачи в браузере через Playwright: открывает сайты, нажимает кнопки, заполняет формы, помогает скачать файл, записаться или забронировать.
- Сохраняет браузерные сессии и может продолжать незавершённую задачу.
- Для паролей, 2FA, captcha, платежей и юридически значимых действий требует явного участия владельца.
- Работает с Google Maps: адреса, места рядом, маршруты и геолокация.

Примеры:

```text
Найди последние новости про OpenAI
Зайди на сайт клиники и запиши меня к врачу
Скачай PDF со страницы
Найди кафе рядом
Как добраться до Красной площади?
```

### Медиа

- Распознаёт голосовые сообщения через OpenAI Whisper и обрабатывает их как обычный запрос.
- Анализирует изображения.
- Делает OCR по присланным картинкам.
- Работает с несколькими изображениями в одном запросе.
- Генерирует изображения через Ideogram.

Примеры:

```text
Что на этом фото?
Прочитай текст на изображении
Нарисуй кота в стиле акварели
```

### Групповые чаты

По умолчанию бот в группе реагирует только на прямое упоминание.

Есть два режима:

| Режим | Поведение |
|-------|-----------|
| Приватный | Посторонним отвечает без раскрытия личных данных владельца. |
| Публичный | Может отвечать всем участникам, но только в рамках разрешённых функций и доменов памяти. |

В публичном режиме доступны диалог, справка, поиск, карты и генерация изображений. Личные функции владельца недоступны другим участникам: чтение переписок, отправка сообщений, переговоры, личные напоминания и админ-команды.

Для каждого чата можно настроить:

- публичный режим;
- разрешённые домены памяти;
- запрещённые темы;
- распознавание владельца по имени и Telegram-никнейму;
- группы чатов для анализа и умного отслеживания важных сообщений.

## Веб-панель управления

После деплоя панель доступна по адресу вида `http://YOUR_VPS_IP:PORT`. Порт, логин и пароль выводятся в конце установки и сохраняются на сервере в `~/.kira-admin-state`.

В панели можно:

- менять API-ключи и токены;
- редактировать параметры PostgreSQL и Qdrant;
- задавать Telegram User Client session string;
- менять часовой пояс и срок хранения выполненных напоминаний;
- включать/выключать публичный режим групп;
- настраивать расписание проактивных сообщений и дайджестов;
- редактировать личность бота: системный промпт, биографию, стиль, настроение, имя и никнейм владельца;
- управлять групповыми чатами, доменами памяти и запрещёнными темами;
- смотреть статус контейнеров;
- перезапускать сервисы после изменения настроек.

Часть фоновых режимов пока настраивается только через `.env.production`: консолидация памяти, фоновое изучение личных переписок и утренний дайджест.

## Установка шаг за шагом

### 1. Подготовить VPS

Подойдёт Ubuntu 20.04+ или Debian 11+. Минимально: 1 CPU, 2 GB RAM, 20 GB диска.

На VPS должны быть:

- git checkout проекта;
- доступ к Docker или возможность поставить Docker через `root`/`sudo`;
- уже поднятый Xray SOCKS5 на `172.17.0.1:10808`.

### 2. Подготовить ключи

Обязательно:

| Что | Где взять |
|-----|-----------|
| OpenAI API key | [platform.openai.com/api-keys](https://platform.openai.com/api-keys) |
| Telegram bot token | [@BotFather](https://t.me/BotFather), команда `/newbot` |
| Telegram User ID владельца | [@userinfobot](https://t.me/userinfobot) |

Опционально:

| Что | Для чего |
|-----|----------|
| Google Maps API key | карты, адреса, маршруты, места рядом |
| Ideogram API key | генерация изображений |
| Telegram API ID + Hash | чтение переписок и отправка от имени пользователя |

### 3. Клонировать репозиторий на VPS

```bash
git clone <repo>
cd kira-mind-bot
```

### 4. Запустить серверный установщик

```bash
./server-install.sh
```

В конце будет напечатан блок вида:

```text
╔══════════════════════════════════════════╗
║        🌐 ПАНЕЛЬ УПРАВЛЕНИЯ              ║
╠══════════════════════════════════════════╣
║  URL:     http://YOUR_IP:8742            ║
║  Логин:   admin                          ║
║  Пароль:  xK7mP2nQ9rL4vY6w              ║
╚══════════════════════════════════════════╝
```

### 5. Настроить личность

В панели управления откройте раздел “Личность” и заполните:

1. имя владельца;
2. Telegram-никнейм владельца без `@`;
3. стиль общения и биографию, если нужно;
4. варианты настроения;
5. сохраните изменения и перезапустите бота.

На сервере после первого деплоя можно защитить локальный `personality.json` от перезаписи при `git pull`:

```bash
git update-index --assume-unchanged personality.json
```

### 6. Получить Telegram Session String

Нужно только для функций Telegram User Client.

```bash
./scripts/get-telegram-session.sh
```

Скрипт авторизует пользовательскую Telegram-сессию через Docker и выведет `TELEGRAM_SESSION_STRING`. Вставьте его в панель управления или `.env.production`.

### 7. Включить публичный режим в группе

1. Добавьте бота в группу.
2. В BotFather отключите privacy mode, если бот должен видеть сообщения в группе.
3. В панели управления откройте “Чаты бота”.
4. Включите публичный режим для нужного чата.
5. Выберите домены памяти, которые можно использовать в этой группе.
6. Добавьте запрещённые темы, если нужно.

## Переменные окружения

Основные настройки можно менять через веб-панель. Для ручной настройки редактируйте `.env.production` на сервере или перезапускайте `./server-install.sh` без `--skip-config`.

### Обязательные

| Переменная | Описание |
|------------|----------|
| `OPENAI_API_KEY` | Ключ OpenAI для LLM, embeddings, web search, Whisper и анализа изображений |
| `KIRA_BOT_TOKEN` | Токен Telegram-бота Kira |
| `KIRA_ALLOWED_USER_ID` | Telegram User ID владельца Kira |
| `DB_PASSWORD` | Пароль PostgreSQL |

### Второй бот

| Переменная | Описание |
|------------|----------|
| `SERGEY_BOT_TOKEN` | Токен второго бота |
| `SERGEY_ALLOWED_USER_ID` | Telegram User ID владельца второго бота |

В Docker Compose поднимаются два профиля из одной кодовой базы: `KiraMindBot` и `SergeyBrainBot`.

### Голосовые ответы ElevenLabs

| Переменная | Описание |
|------------|----------|
| `ELEVENLABS_API_KEY` | Ключ ElevenLabs для генерации голосовых ответов |
| `ELEVENLABS_VOICE_ID` | ID голоса Nastya. Рекомендуемый вариант, чтобы не зависеть от поиска по имени |
| `ELEVENLABS_VOICE_NAME` | Имя голоса для поиска, если `ELEVENLABS_VOICE_ID` не задан. По умолчанию `Nastya` |
| `ELEVENLABS_MODEL_ID` | Модель TTS. По умолчанию `eleven_v3` |
| `ELEVENLABS_OUTPUT_FORMAT` | Формат аудио ElevenLabs. По умолчанию `mp3_44100_128`, как в quickstart и на скрине; для Telegram voice бот перекодирует файл в OGG/Opus |
| `ELEVENLABS_VOICE_STABILITY` | Stability из настроек голоса, например `0.5` |
| `ELEVENLABS_MAX_TEXT_CHARS` | Максимальная длина текста для одного голосового ответа, по умолчанию `9500` |

При локальном запуске с MP3-форматом ElevenLabs нужен установленный `ffmpeg`: бот заранее проверит его наличие перед запросом к ElevenLabs и вернёт текстовый ответ, если перекодирование в Telegram voice недоступно. Docker-образ уже устанавливает `ffmpeg`.

### База и векторная память

| Переменная | Описание |
|------------|----------|
| `DB_HOST` | Хост PostgreSQL, обычно `postgres` |
| `DB_PORT` | Порт PostgreSQL, обычно `5432` |
| `DB_USER` | Пользователь PostgreSQL |
| `DB_NAME` | Имя базы |
| `VECTOR_PROVIDER` | Провайдер векторной памяти, практически используйте `qdrant` |
| `QDRANT_URL` | URL Qdrant, обычно `http://qdrant:6333` |
| `QDRANT_API_KEY` | Ключ Qdrant, если включена аутентификация |
| `VECTOR_SEARCH_THRESHOLD` | Глобальный порог релевантности поиска памяти |

`PineconeVectorService` есть в коде, но большинство методов в нём пока являются заглушками. Рабочий вариант по умолчанию: Qdrant.

### Обязательный VPN для контейнеров

| Переменная | Описание |
|------------|----------|
| `HTTP_PROXY` | Должна быть `socks5h://172.17.0.1:10808` |
| `HTTPS_PROXY` | Должна быть `socks5h://172.17.0.1:10808` |
| `ALL_PROXY` | Должна быть `socks5h://172.17.0.1:10808` |
| `NO_PROXY` | Должна включать `localhost,127.0.0.1,postgres,qdrant` |

`server-install.sh` записывает эти значения автоматически. Без них серверный сценарий считается неполным, потому что внешний трафик контейнеров должен идти через Xray VPN.

## Архитектура

```text
Telegram Bot API / Telegram User Client
              |
              v
        grammy + session
              |
              v
        Orchestrator
   классификация интента -> план -> агенты
              |
              v
  conversation / reminder / health / browserTask
  readMessages / sendMessage / negotiateOnBehalf
  webSearch / maps / imageAgent / imageGeneration
  capabilities / selfStudy / unclearIntent
              |
              v
  Services: PostgreSQL, Qdrant, OpenAI, Google Maps,
            Ideogram, Playwright, Telegram MTProto
              |
              v
  Schedulers: kiraLife, dmReport, memoryInsight,
              memoryConsolidation, personalChatMemory,
              reflection, morningDigest, chatGroupTracker
```

Основные части:

- `index.ts` - запуск бота, обработка Telegram events, callbacks, медиа и планировщиков.
- `orchestrator.ts` - классификация интентов и маршрутизация.
- `orchestration/planner.ts` и `orchestration/executor.ts` - построение и выполнение цепочек агентов.
- `agents/*` - прикладные агенты: диалог, напоминания, Telegram, браузер, карты, здоровье, изображения и т.д.
- `services/*` - интеграции, планировщики, репозитории и инфраструктурные сервисы.
- `utils/enhancedDomainMemory.ts` и `services/QdrantVectorService.ts` - долговременная память.
- `admin-panel/*` - React/Vite UI и Node.js backend панели управления.
- `docker-compose.yml` - legacy compose для старого удалённого деплоя с локальной машины.
- `docker-compose.server.yml` - основной compose для `server-install.sh` и запуска прямо на VPS.
- `server-install.sh` - основной сценарий установки и redeploy прямо на VPS после `git pull`.

## Важные замечания

| Тема | Замечание |
|------|-----------|
| Доступ | Личный режим рассчитан на одного владельца через `KIRA_ALLOWED_USER_ID`. |
| Данные | PostgreSQL и Qdrant живут в Docker volumes на вашем сервере. |
| Telegram Client | Без пользовательской сессии недоступны чтение переписок, контакты, отправка от имени пользователя и переговоры. |
| Google Maps | Без ключа Google Maps недоступны карты и маршруты. |
| Ideogram | Без ключа Ideogram недоступна генерация изображений. |
| Здоровье | Дневник здоровья фиксирует наблюдения, но не ставит диагнозы. |
| Браузер | Пароли, 2FA, captcha, платежи и критичные действия требуют участия владельца. |
| Группы | Для полноценной работы в группах отключите privacy mode у бота в BotFather. |
| Публичный режим | Заполните Telegram-никнейм владельца в личности, чтобы бот корректно распознавал упоминания. |
| Pinecone | В коде есть провайдер Pinecone, но рабочий и поддерживаемый вариант сейчас Qdrant. |
