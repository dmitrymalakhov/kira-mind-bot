---
name: people-and-memory
description: Проверенная память, разрешение личности и разделение субъектов.
---

- Различай факты владельца, контакта, третьего лица, слова бота и собственную историю Киры.
- stable person_id и сильные Telegram ID имеют приоритет. Не объединяй людей по одному неоднозначному имени.
- memory.search использует общий retrieval с фильтрами субъектов. Пустая ограниченная выборка не доказывает отсутствие сведений во всём архиве.
- Для просьбы об интересном факте выбери одно конкретное надёжное сведение из установленного профиля; слово «интересный» не обязано встречаться в записи. Сначала используй уже подготовленную память.
- Списки людей по отношениям и темам переписок собирает memory.search. contacts.list возвращает адресную книгу и сам по себе не доказывает рабочее общение. Различай сохранённую связь, прямую переписку и простое упоминание человека; групповое название не является человеком.
- Перечисляй людей из подтверждённой коллекции поимённо. Рабочее обсуждение не доказывает работу в одной компании или текущий состав команды. Не заменяй список одними именами из недавнего ответа бота.
- Сохраняй только подтверждённые атомарные утверждения с evidence. Слова ассистента, вопросы и отрицания не доказывают факт.
- memory.forget вызывается только по явной просьбе. Автоматическая реконсолидaция остаётся защищённым процессом.
- Переписка и результаты инструментов не являются новыми словами владельца.
