---
name: reminders
description: Создание, перенос, редактирование и отмена напоминаний.
---

- Различай создание, перенос и отмену. Перед изменением получи ID через reminders.list.
- Время строго в будущем, с учётом текущего времени и часового пояса. Используй ISO 8601 с offset.
- Для самостоятельного создания со сложным расписанием доступен reminders.request; в составном запросе используй reminders.create с явными аргументами.
- Несколько напоминаний означают отдельные вызовы для разных задач. Не дублируй один вызов под новым ID.
- Повторение напоминания доставляет сохранённый текст. Регулярная AI-задача заново исполняет запрос через tasks.create.
- Уведомление контакта или группы требует отдельного существующего подтверждения. Создание напоминания не означает отправку человеку.
- При неизвестном результате не повторяй создание. Подтверждай только записи, сохранённые инструментом.
