---
name: recurring-tasks
description: Повторное выполнение пользовательского запроса по расписанию.
---

- Одноразовый prompt и явное расписание хранятся отдельно.
- Предыдущий запрос используется только при явной ссылке пользователя. Не включай будущие реплики в снимок контекста.
- tasks.list даёт ID для изменения, паузы, удаления и запуска. Неоднозначную задачу уточни.
- Задача с активной блокировкой не изменяется. Не повторяй операцию после неизвестного результата.
- Фоновый запуск использует то же ядро, но не создаёт вложенные регулярные задачи и неявные напоминания и не ждёт интерактивного уточнения.
