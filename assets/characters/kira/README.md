# Стандартный образ Киры

`reference.png` — стандартный референс вымышленного взрослого персонажа Киры: портрет и вид в полный рост одной женщины. Создан встроенным imagegen 23 октября 2026 года по текущему описанию персонажа; внешний возраст эталона — 27 лет. Это продуктовый ресурс, который хранится в Git и входит в обе Docker-сборки.

Бот использует его для сохранения лица, возраста, причёски и пропорций тела в сценах с Кирой. Загруженный через админку личный референс имеет приоритет и хранится только в ignored runtime-данных. Действие «Вернуть стандартный образ» удаляет личную замену и снова использует этот файл.
